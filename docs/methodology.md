# 口径说明

本账本只记录厂商公开的 API 标价，以及把标价折成另一种货币时用到的汇率。它不记录渠道价、聚合平台价、订阅套餐价，也不记录没有写出来源的数字。

## 一条记录要有什么

每条模型一个 YAML 文件，至少包括：厂商、API 模型 ID、上下文、每百万 tokens 的输入价和输出价、账单币种、来源 URL、检索日和核验日。发布日期只有在官方页面写明时才填写。页面没写，就留空，不从模型 ID 里的数字猜。

来源必须是 https 的官方定价页或官方模型页。汇率中间价的外管局查询页目前是 http，因此汇率允许这一条例外，并同时引用 https 的新闻转述互相印证。

## 入口价怎么选

表上的那一个数字是入口价，不是所有档位的平均。

- 用标准实时价，不用 Batch、Flex、Fast 或高速基础设施的加价。
- 有上下文或峰谷分档时，入口价取最低的常规档，其余档位原样保留。
- DeepSeek 的入口价是空闲时段、缓存未命中。高峰是它的两倍，写在分档里。
- 页面同时给出原价和限时折扣时，入口价是核验日仍在执行的折扣价，原价另存。
- 页面写了未来生效日时，现价留在入口价，未来价写在 `scheduled`，不提前覆盖。
- 缓存命中不算进输入单价。它有自己的字段。

## 人民币折算

2026-11-07 是周六。折算使用前一交易日、2026-11-06 的银行间外汇市场人民币汇率中间价。外管局表格把美元标成 671.68，单位是人民币元 / 100 美元，折合 1 美元 = 6.7168 元。同一天中国新闻网转述中国外汇交易中心的公告也是 6.7168。

折算用四舍五入（half up）保留 6 位小数。账单已经是人民币的，人民币栏等于原价；账单是美元的，美元栏等于原价。另一个数字是折算额，不能拿去和发票核对。

有的厂商同时公布另一种货币，而且和中间价折算对不上。DeepSeek 英文定价页就是这样。那种价格记在 `alternate_lists`，不混进折算栏。

## 页面位置

每条来源除了 URL，还要写 `section_zh`：页面上的哪一节、哪张表、哪一行。只写「定价页」不够。复核的人应该能按这句话找到单元格。

## 历史

`data/models` 是当前价。`data/history` 里每个模型一份只追加的观察记录。`snapshots/` 是某一天的整本快照，写成之后不能改内容。变动说明由「当前数据」相对「上一份快照」生成。没有上一份快照时，新增模型算首次建档。

更早的单价只有在官方页面白纸黑字写了旧价和新价时才写入历史。生效日用厂商公告的日期，检索日另记。不把版本号、传闻或中间价倒推当成旧价。通义千问 Max 在 2025-02-07 的降价是目前唯一这样入账的变动。

改价的方式是：改模型文件，在历史末尾追加一条，用新的核验日另存一份快照。不许改旧观察，也不许覆盖旧快照。
