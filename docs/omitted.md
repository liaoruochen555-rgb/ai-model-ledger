# 未收录与未采信

下面这些不是漏记，是核验之后决定不写进单价。

## 官方材料互相冲突

- DeepSeek `deepseek-v4-pro` 仍出现在 [定价页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing)，版本号 DeepSeek-V4-Pro-0813，并有独立价格。2026-09-10 的 [发布说明](https://api-docs.deepseek.com/zh-cn/news/news260910) 写明，北京时间 2026-09-14 12:00 之后、到 V4.1 Pro 上线之前，这个名字会路由到 V4.1 Flash 并按 Flash 计费。两份官方材料对「现在扣哪一档」说法不同，本版不单列 Pro。
- DeepSeek 英文首页展示过另一套更低的美元价。API 定价页的空闲档是输入 0.15 美元、输出 0.6 美元。账本采用定价页，不采用首页。

## 同一模型、两张价目

- Kimi 中国站 [定价页](https://platform.kimi.com/docs/pricing/chat) 把 `kimi-k3.1-pro` 标为输入 13 元、输出 68 元。国际站首页把同名产品标为 2 美元 / 10 美元。两者不是中间价能换算的关系。本版只收中国站。该页的 Markdown 导出会把表格抽空，数字取自同一官方页面的文档源码。
- 通义千问在百炼的华北 2（北京）、全球、美国、国际部署上单价不同。本版只收北京。

## 看到了，但没有写成单价

- 智谱 GLM-5.3-Flash 的 [定价表](https://docs.bigmodel.cn/cn/guide/start/pricing) 是输入 0.8 元、输出 2.8 元。模型介绍另称限时折扣可以到 GLM-5.3 的 1/20。介绍页没有把折后的 token 单价印出来，账本不自行把 8 元除以 20。
- 多家厂商写了 Batch 半价或六折、缓存「享有折扣」，但没有给出命中单价。只有页面印出数字的缓存价才入库。
- 缓存存储若只写「限时免费」且没有期满后的单价，不把 0 写成永久价格。
- Gemini 的 Batch、Flex 和按小时的缓存存储没有并进输入单价。存储价写在备注。
- OpenAI 的 Batch、Flex、Fast、Ultrafast，以及区域驻留 10% 加价，都不是入口价。
- xAI 的美国区域端点是全球价的 1.1 倍。Grok 4.7 Fast 不在公开 API 上销售。
- Kimi K2 里，`kimi-k2.6` 仍印在中国站价目表上，本版作为即将下线的低价档收录。`kimi-k2.7-code` 与其高速版同页有价，v0.1 没有继续展开。
- 按张、按秒、按次计费的图像、视频、语音和搜索接口未收录。

## 价格能看到，上下文或发布日不能同时核验

- OpenAI 现行 Standard 表已收录 Astra、6.1 Sol、6.1 Terra、6 Sol、6 Luna、5.6 Sol、5.6 Terra、5.6 Luna。gpt-5 与 gpt-4.1 保留并标成已弃用。更老的 gpt-4o、gpt-4o-mini、gpt-5-mini 仍在价目表下半截，本轮没有逐个打开模型页核对上下文，继续不收。
- GPT-5.6 Sol 写明促销到 2026-11-30，页面没有印出之后的单价，所以没有推算期满价。
- 智谱文本表上还有 GLM-5.1、GLM-5-Turbo、GLM-5.2。本轮补了仍在售的基座 glm-5，其余没有逐条展开。
- xAI 的 grok-4.6 与 grok-4.7 同价。本轮补的是模型页写了 1,000,000 上下文、且比 4.7 更低的 grok-4.3。
- 不少模型的官方页没有发布日期。这些条目的 `release` 留空，不用版本号里的月日充数。Grok 4.20 的模型 ID 含有 `0309`，没有被当成发布日。
